# Спецификация метрик (`metric_spec.md`)

## 1. Единица оценки и выборка
* **Задача:** поиск визуально-атмосферных референсов сцен по текстовому описанию.
* **Единица оценки:** один пользовательский запрос.
* **Выборка `validation`:** `12` карточек сцен (`V001`–`V012`) и `12` запросов (`Q01`–`Q12`): `6` буквальных запросов (`literal`) и `6` переформулировок (`paraphrase`).
* **Глубина выдачи:** `k = 3` (оцениваются первые 3 карточки в ответе).

## 2. Шкала релевантности
Каждая карточка из `validation` для конкретного запроса оценивается по трёхбалльной шкале:
* **`2`** — совпадает и сцена/объект, и атмосфера/свет (главный референс).
* **`1`** — совпадает смежная атмосфера/свет или частичный признак, но сцена другая.
* **`0`** — карточка не подходит по сцене и атмосфере.

В текущем наборе у каждого запроса отмечены `3` релевантные карточки (`2, 2, 1`), остальные карточки имеют оценку `0`.

## 3. Главная и защитные метрики
* **Главная метрика:** средний **`NDCG@3`**.
  * Полезность позиции (`gain`) считается по формуле $2^{\text{relevance}} - 1$ (то есть для оценок `2, 1, 0` gain равен `3, 1, 0`).
  * Дисконт для позиции $i$ (нумерация с `1`, то есть `1, 2, 3`) равен $\log_2(i + 1)$.
  * Нормировка идёт на идеальный порядок (`IDCG@3`) для того же запроса.
* **Защитные метрики:**
  1. Средний **`Recall@3`** — не ниже значения baseline (`0.3611`), чтобы улучшение ранжирования не теряло релевантные карточки.
  2. **Доля карточек без допуска в выдаче** — строго `0` (недопустимо выдавать материалы без прав/допуска).
  3. **Воспроизводимость** — при повторном запуске на тех же данных результат и `Config hash` (`c3d798971913`) не меняются.

## 4. Пороги и правила для особых случаев
* **Порог качества для alpha-версии:** средний `NDCG@3 >= 0.70` на `validation` (на baseline получено `0.5000`).
* **Пустая выдача:** если запрос не дал совпадений (например, все слова вне словаря `train`), возвращается пустой список, а `NDCG@3` и `Recall@3` для этого запроса равны `0`.
* **Запросы без релевантных объектов:** если в будущем появятся запросы, у которых в каталоге вообще нет подходящих карточек (`IDCG@3 = 0`), их нужно оценивать отдельно как проверку корректного отказа, а не смешивать в среднюю `NDCG@3`.
* **Продуктовая цель** (например, быстрый подбор референса за пару минут реальным автором) не измеряется по этой таблице — для неё нужна проверка с пользователями.
